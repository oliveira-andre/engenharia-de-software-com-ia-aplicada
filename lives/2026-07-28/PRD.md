Se baseie na imagem de inspiração ( @resources/inspiration.webp ) para criar uma landing page, use React + TypeScript com Vite e Tailwind para estilizações (todos na versão `latest`).

## Tools

### MCP

- Use o [**Context7**](https://context7.com/llms.txt) para documentações atualizadas
- Use o [**Magnific**](https://docs.magnific.com/modelcontextprotocol.md) para gerar imagens conforme necessário

### Skills

- Utilize a skill /engineering para gerar códigos com boas práticas de desenvolvimento e DX (Developer Experience)
  - Garanta desacoplamentos inteligentes entre componentes para maior manutenibilidade
  - Separe componentes de UI e lógica de negócio (hooks, context, etc.)
- Utilize a skill /ui para garantir o equilíbrio entre o visual (UI) e a experiência do usuário (UX)
  - Garanta que toda transição tenha suavidade
  - Garanta que toda interação tenha feedback visual

## Revisão (Loop)

- Utilize a skill /cdp para comparar visualmente o estado da landing page com a referência
  - Teste contra resoluções de desktop, tablet e mobile.
- Utilize a skill /lagune para garantir a segurança do projeto de ponta a ponta

## Sobre o Projeto

Ao invés de "Sentry", como na imagem de inspiração, o nome do projeto é **Safer**: um projeto fictício para ensinar sobre UX e DX de forma simplificada com IA.
