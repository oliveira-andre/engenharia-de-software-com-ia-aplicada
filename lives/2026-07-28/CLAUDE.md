# Safer

A fictional landing page used to teach UX and DX with AI, built with React, TypeScript, Vite, and Tailwind, all on `latest`.

- `PRD.md` holds what and how to build, `README.md` holds how to set the environment up.

## Scripts

- `npm run lint`: checks the whole repository against Prettier.
- `npm run lint:fix`: writes the formatting fixes.
- `npm run typecheck`: runs TypeScript without emitting.

## Conventions

- Run `lint` and `typecheck` before treating any change as done.
- Prettier owns formatting, so never format by hand.
